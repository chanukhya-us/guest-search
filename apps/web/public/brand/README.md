# Brand assets

Place the official IHG logo here as `ihg-logo.svg`. `BrandLogo` loads
`/brand/ihg-logo.svg` and falls back to a text wordmark when the file is absent
or fails to load (Req 23.6).

Do not copy logo files from ihg.com or third-party logo aggregators (Req 23.7).
The file must come from IHG Brand (tracked as Blocker B8).
